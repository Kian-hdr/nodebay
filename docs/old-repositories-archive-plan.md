# Old repository archive plan

No action in this plan has been applied publicly.

## `Kian-hdr/boring.notch`

Purpose: public GitHub fork of `TheBoredTeam/boring.notch` used to preserve and publish the first Boring Notch MarkItDown work. Current URL: https://github.com/Kian-hdr/boring.notch. It has issues disabled, no open pull requests, and one prerelease named **Boring Notch MarkItDown 2.8-beta.0-markitdown.1 (Apple Silicon)**.

Proposed README introduction:

> **Archived repository**
>
> This repository is archived and no longer maintained. Development continues as Nodebay, a local-first macOS utility bay based on Boring Notch.
>
> Source, documentation, releases, and Homebrew installation are available at: https://github.com/Kian-hdr/nodebay
>
> Historical source, release artifacts, attribution, and license information remain available here for provenance and GPL-3.0 compliance.

Proposed historical release prefix:

> **Historical Boring Notch MarkItDown build.** This prerelease is preserved for provenance and is not the current Nodebay release. Current development and supported downloads are at https://github.com/Kian-hdr/nodebay.

## `Kian-hdr/homebrew-boring-notch-markitdown`

Purpose: public Homebrew tap for the historical Apple Silicon Boring Notch MarkItDown prerelease. Current URL: https://github.com/Kian-hdr/homebrew-boring-notch-markitdown. It has no releases, open issues, or open pull requests.

Proposed README introduction:

> **Archived Homebrew tap**
>
> This repository is archived and no longer maintained. Do not install the historical Boring Notch MarkItDown cask for new setups.
>
> Nodebay source, releases, and current Homebrew installation are available at: https://github.com/Kian-hdr/nodebay

## Migration response for any issue or pull request opened before archival

> Thank you for the report or contribution. This repository is now archived and read-only. Nodebay development continues in the standalone public repository at https://github.com/Kian-hdr/nodebay. Please search the Nodebay issue tracker and open a new issue or pull request there if the topic still applies. Historical source and license records remain available in this repository.

After the notices and historical release annotation are visible, both repositories will be archived through GitHub so they become read-only. Neither repository will be deleted or made private.
