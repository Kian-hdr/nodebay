# Media downloader

Nodebay accepts explicit HTTP or HTTPS media URLs through drop, the shelf's Add Link popover, Downloader Settings, Command-V while the pointer is inside an open notch, or the download control shown for a connected YouTube browser-tab media source. All entry points create the same persistent job. yt-dlp inspects and downloads directly from the Mac to Nodebay-managed local storage by default, which avoids repeated Downloads-folder permission prompts. Users can select a custom download folder once in Settings; Nodebay retains its security-scoped bookmark.

Automatic is the recommended default and does not show a format popup. YouTube Music and extractor-confirmed audio-only or structured track metadata select MP3. Ambiguous standard YouTube content selects MP4 so video is not discarded. The job records the classification confidence and reason, and its format control can override one item as Video, Audio, or Best Original. Settings also provide Always Video, Always Audio, and Ask Every Time modes while retaining the saved resolution and bitrate controls. MP3 never starts when FFmpeg is unavailable.

Playlists always require confirmation. In Automatic mode, Nodebay fully inspects and classifies each item rather than guessing one format for the whole playlist. Fixed Audio or Video settings and one-time overrides apply one format to every item. Partial successes are preserved, and completed playlist items become a File Stack.

URLs are passed as structured arguments, credentials in URLs are rejected, output templates are restricted, path traversal is rejected, browser cookies and plugins are disabled, and no shell is used. Downloads use a job-owned staging directory and collision-safe promotion. Cancellation cleans only staging data; completed and partially successful files remain in the selected directory and are added to the shelf. YouTube has the primary tested experience. Other yt-dlp sites are explicitly shown as experimental because upstream site support changes. Copyright and service permissions remain the user's responsibility.
