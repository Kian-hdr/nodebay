# Media downloader

Nodebay accepts explicit HTTP or HTTPS media URLs through drop, the shelf's Add Link popover, Downloader Settings, Command-V while the pointer is inside an open notch, or the download control shown for a connected YouTube browser-tab media source. All entry points create the same persistent job. yt-dlp inspects and downloads directly from the Mac to Nodebay-managed local storage by default, which avoids repeated Downloads-folder permission prompts. Users can select a custom download folder once in Settings; Nodebay retains its security-scoped bookmark. Users select MP4 and a maximum resolution, MP3 and a bitrate, Best Original, or a saved automatic default. Playlists always require confirmation and completed playlist items become a File Stack.

URLs are passed as structured arguments, credentials in URLs are rejected, output templates are restricted, path traversal is rejected, browser cookies and plugins are disabled, and no shell is used. Downloads use a job-owned staging directory and collision-safe promotion. Cancellation cleans only staging data; completed and partially successful files remain in the selected directory and are added to the shelf. YouTube has the primary tested experience. Other yt-dlp sites are explicitly shown as experimental because upstream site support changes. Copyright and service permissions remain the user's responsibility.
