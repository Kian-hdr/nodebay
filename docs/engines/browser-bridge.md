# Browser media bridge

- Purpose: proposed opt-in enumeration and control of individual compatible browser media tabs
- Version: unavailable; not shipped
- Status: no extension or native bridge is bundled in the current source
- Intended behavior: local native messaging only, with explicit browser installation and permissions
- Inputs and outputs: only user-approved media-tab identity, metadata, state, and supported control messages
- Permissions: browser extension permission and local native-messaging registration
- Failure: disconnect gracefully and fall back to system Now Playing
- Diagnostics: connection and permission state without browsing history
- Source and license: to be recorded before any implementation is distributed

Nodebay does not currently claim individual-tab support. Browser vendors and media services do not endorse Nodebay.
