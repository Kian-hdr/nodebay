# Media downloader

Nodebay accepts explicit HTTP or HTTPS media URLs through drop, paste, or the Add Download field. yt-dlp inspects and downloads directly from the Mac to the configured directory. Users select MP4, MP3, best original, or a saved default; playlists require confirmation.

URLs are passed as structured arguments, credentials in URLs are rejected, output templates are restricted, path traversal is rejected, browser cookies and plugins are disabled, and no shell is used. Completed files remain in the selected download directory and are added to the shelf. Copyright and service permissions remain the user's responsibility.
