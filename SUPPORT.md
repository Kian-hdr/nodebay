# Nodebay support

Use GitHub Issues for reproducible Nodebay bugs and feature requests after searching existing reports. Use GitHub Discussions only if it is enabled for the repository.

Before reporting a bug, record the Nodebay version, macOS version, Mac model and architecture, display configuration, relevant engine versions, and concise reproduction steps. Sanitize logs and confirm whether original files remained unchanged.

Never upload private documents, cookies, downloaded media, credentials, personal filenames, or full unredacted logs. For vulnerabilities, follow [SECURITY.md](SECURITY.md) instead of filing a public issue.

Questions about Boring Notch itself belong in the [upstream Boring Notch repository](https://github.com/TheBoredTeam/boring.notch). Questions about an unmodified engine should be directed to that engine's official project.
